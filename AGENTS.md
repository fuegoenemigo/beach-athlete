# Lokale Arbeitsvorgabe

Der Nutzer möchte künftig keine Programme auf `C:` installieren, außer wenn es technisch unbedingt nötig ist. Eigenständige Programme bevorzugt unter `E:\APPS\ChatGPT-Installationen` installieren und dort in `README.md` dokumentieren. Projektabhängigkeiten bleiben im Projektordner auf `E:`. Vor einer unvermeidbaren Installation auf `C:` den Grund erklären und den Nutzer fragen.
